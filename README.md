## ⚙️ Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/QuangVinhNT/nettech.git
   ```

2. Move into the project folder:
   ```bash
   cd nettech
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
